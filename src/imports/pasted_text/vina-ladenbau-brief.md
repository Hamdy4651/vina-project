**Experience → Projekte → Projekte → Projekte → Prozess → Kunden → Vertrauen → Kontakt**

Die Projektbilder müssen deshalb deutlich mehr Raum bekommen als auf einer normalen Firmenwebsite.

* Lightbox / Projekt-Detailansicht

# 26. ANIMATION SYSTEM

Animationen müssen langsam und hochwertig sein.

Nutze:

* opacity
* transform
* clip-path
* scale
* translate
* mask reveal
* image zoom
* parallax
* horizontal movement
* staggered text
* line reveal

Beispiel:

Text:

translateY(100%)

→

translateY(0)

Bild:

scale(1.08)

→

scale(1)

Linie:

scaleX(0)

→

scaleX(1)

Die Referenzimplementierung verwendet bereits sehr ruhige Reveal-Transitions mit unterschiedlichen Delays und Easing-Kurven. Dieses Prinzip soll übernommen werden.
